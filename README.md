#How to play
"Go live" with index.html in VSCode using the Live Server extension by Ritwick Dey Extension (bottom right of the screen).

#Instructions
The file words.js contains two lists: SOLUTIONS and VALID_GUESSES. The latter are words which can be guesses when playing the game and the former (a subset) are possible solution words. SOLUTIONS should only contain proper words, no plural words, conjugated verbs or participles. By default SOLUTIONS always is contained in VALID_GUESSES. When running the game, a random word from SOLUTIONS is picked as the solution. Currently the list contains only 1 word, so the developer can be able to manually enter a solution word.

Please add new words to VALID_GUESSES first, we then choose which words should be valid solutions later. You need not worrying about duplicates, as the code doesn't care. :)
